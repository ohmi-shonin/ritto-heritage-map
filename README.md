# 栗東市歴史遺産マップ
## このアプリについて
- 滋賀県栗東市の歴史遺産・文化財を表示する専用Webアプリです。
- OpenStreetMapのデータから栗東市の歴史、文化関連の地物を表示します。
- 栗東市の豊かな歴史と文化遺産を地図上で探索できます。

## ベースプロジェクト
- このアプリは「みんなの歴史文化マップ」をベースに栗東市専用にカスタマイズしています。
- 元プロジェクト: https://github.com/armd-02/openhc-map/
- Community Mapmakerフレームワークを使用: https://github.com/K-Sakanoshita/community_mapmaker

## 栗東市について
- 滋賀県南部に位置する歴史豊かな都市
- 古墳時代から続く長い歴史を持つ
- 多数の文化財・史跡が点在する文化都市
